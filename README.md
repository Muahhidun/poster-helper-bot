# Poster Helper

Личный веб-инструмент для управления операциями ресторана через Poster POS.

## Текущая архитектура

- Flask — основной интерфейс для проверки, редактирования и отправки операций в Poster.
- WhatsApp — входящие накладные и сообщения обрабатываются последовательной очередью; бот создаёт только локальные черновики и присылает один итог по пакету. Утверждение через WhatsApp пока не включено.
- Telegram — только исходящие уведомления и отчёты. Команды, входящие сообщения, webhook и Mini App в продакшене отключены.
- Фоновые задачи — синхронизация Poster, ежедневные операции, напоминания, отчёты и мониторинг цен.
- `mini_app/` — архив исходного React-прототипа; он не собирается, не публикуется и не участвует в работе сервиса.

## Возможности

- расходы и поставки;
- закрытие смен и расчёт зарплат;
- переводы и ежедневные транзакции;
- OCR накладных и AI-парсинг;
- справочники и алиасы поставщиков/категорий;
- отчёты, уведомления и мониторинг цен через Telegram.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 start_server.py
```

Сайт будет доступен на `http://localhost:5000`.

Для разработки старого интерактивного Telegram-кода отдельно существует запуск `python3 bot.py`, но он не используется в Railway и не является поддерживаемым пользовательским интерфейсом.

## Проверка

```bash
source .venv/bin/activate
pytest -q
```

## Развёртывание

Railway запускает Flask через Gunicorn. Используется один worker-процесс, чтобы планировщик не отправлял одинаковые отчёты несколько раз; HTTP-запросы обслуживаются несколькими потоками.

React/Node.js для сборки не требуются.

## Конфигурация

Основные значения задаются через `.env` или переменные Railway:

- `TELEGRAM_BOT_TOKEN`, `ALLOWED_USER_IDS`, `ADMIN_USER_IDS`;
- `POSTER_ACCOUNT`, `POSTER_TOKEN`, `POSTER_USER_ID`;
- ключи AI/OCR-сервисов, которые используются соответствующими функциями;
- параметры PostgreSQL/Railway и директории постоянного хранилища.
- `WHATSAPP_BATCH_WINDOW_SECONDS` и `WHATSAPP_BATCH_SETTLE_SECONDS` — окно объединения сообщений и пауза перед итогом пакета.

Секреты не должны попадать в Git.
